# achievement-lab

Transparent sandbox for testing GitHub profile achievements without touching third-party repositories.

## Guardrails

- Use only repositories owned by `naoyamd`.
- Do not spend money or contact third parties.
- Keep credentials and private data out of commits and discussions.

## Recorded experiments

- Galaxy Brain: two accepted answers in [Q&A #1](https://github.com/naoyamd/achievement-lab/discussions/1) and [Q&A #2](https://github.com/naoyamd/achievement-lab/discussions/2).
- Heart On Your Sleeve: a heart reaction was added to Q&A #1; no badge was displayed at the time of the check.
- Pair Extraordinaire: co-authored pull requests were merged in [`stl-compare`](https://github.com/naoyamd/stl-compare/pulls?q=is%3Apr+is%3Amerged).
